🌸 Bloom Garden - Flower Shop Website

A simple and responsive Flower Shop Website built using HTML5 and Bootstrap 5. This project demonstrates the use of Bootstrap components such as the navigation bar, tables, forms, grid system, carousel, buttons, and responsive layouts.

📌 Features
🌿 Responsive Header with Navigation
🌸 Welcome Section
📋 Flower Categories List
💰 Flower Price Table
🖼️ Flower Gallery using Bootstrap Grid
🛒 Order Form
🎠 Bootstrap Carousel
🎉 Promotional Banner
📄 Responsive Footer
📱 Mobile-Friendly Design
🛠️ Technologies Used
HTML5
Bootstrap 5.3
CSS (Bootstrap Utility Classes)

Container
Grid System (row, col)

Table
Forms
